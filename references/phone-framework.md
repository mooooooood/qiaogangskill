# 电话销售框架与话术指南

> 本文件为中域教育电话销售话术生成提供方法论支持和模板参考。

## 一、电话销售 vs 文字销售的核心差异

电话销售与微信/文字销售有本质不同，需要特别注意：

| 维度 | 电话销售 | 文字销售 |
|------|---------|----------|
| 注意力 | 客户注意力易分散 | 可反复阅读 |
| 节奏 | 顾问主导节奏 | 双方对等 |
| 情绪 | 声音传递情绪 | 文字传递信息 |
| 反馈 | 即时反馈，可调整 | 可思考后回复 |
| 信任 | 声音建立信任 | 内容建立信任 |
| 时长 | 3-10分钟黄金期 | 不限时 |

**电话独有优势**：
- 声音有温度，更容易建立情感连接
- 可以即时判断客户状态并调整
- 不容易被忽略（微信消息可能被淹没）
- 成交效率更高

**电话独有挑战**：
- 前30秒决定客户是否愿意听下去
- 异议处理需要即时反应
- 不可能边查资料边讲
- 被挂电话的风险

## 二、电话销售标准流程

### 阶段1：开场建立信任（0-30秒）

**目标**：让客户愿意听你讲下去

**开场白三要素**：
1. 我是谁（自报家门）
2. 为什么打电话（来意说明）  
3. 对客户的价值（利益预告）

**模板1：信息登记型开场**
```
王老师您好，我是中域教育的课程顾问小林。
您之前在我们这里登记了想了解中医课程的信息，
今天打这个电话就是想跟您简单聊一下，
看看哪门课程最适合您的情况。
大概占用您3分钟，您方便吗？
```

**模板2：活动邀约型开场**
```
李姐您好，我是中域教育的小林。
我们最近有一个古法焕颜的免费体验课，
我看您之前关注过我们的中医课程，
所以特别给您留了一个名额。
这个课特别适合想系统了解中医入门的朋友。
您现在方便聊两句吗？
```

**关键技巧**：
- 声音要热情但不夸张，稳重但不冷淡
- 开场语速不要过快，给对方消化时间
- 问“方便吗”是给客户选择权，降低抵触
- 如果客户说不方便，果断约下次，不要纠缠

### 阶段2：需求挖掘（1-3分钟）

**目标**：了解客户真实需求，为后续匹配课程做准备

**SPIN法则在电话中的应用**：

**S - Situation（情况问题）**：
```
您现在是在做什么工作呢？
之前有没有接触过中医这一块？
是自己感兴趣还是朋友推荐的？
```

**P - Problem（困难问题）**：
```
为什么想学中医呢？是工作需要还是自己感兴趣？
现在的工作觉得怎么样？有没有想过换个行业？
之前有没有试过自己看书学？
```

**I - Implication（牵扯问题）**：
```
如果继续这样下去，一年后您觉得会有什么变化？
身边有没有人抓住机会转行成功的？
您觉得年龄再大一点，还有精力学一门新手艺吗？
```

**N - Need-payoff（需求回报问题）**：
```
如果学会一门中医技术，您最想做什么？
想象一下，三个月后您能给家人调理身体，那种成就感...
```

**关键技巧**：
- 多用开放性问题，少用“是不是”“对不对”
- 听客户说，多听少说
- 关键信息做笔记（职业、年龄、学习目的）
- 找到客户的核心驱动（赚钱/健康/兴趣/焦虑）

### 阶段3：价值塑造（3-5分钟）

**目标**：让客户觉得这门课值得学、值得报

**价值塑造五步法**：

**1. 抓住痛点**：
```
您刚才说到现在的工作看不到前景，想学门手艺但不知道怎么开始，对吧？
```

**2. 展示课程**：
```
我们的一柔性正骨整容术课程，是中域教育的明星课程。
由临床15年的正骨师傅手把手教，
从零基础到独立上手，课程体系非常完整。
```

**3. 差异化价值**：
```
市面上正骨课不少，但我们不一样——
首先，老师都是有临床实战经验的，不是纸上谈兵；
第二，课程设计从零开始，零基础完全跟得上；
第三，学完之后我们有答疑群，不会让您孤军奋战；
第四，现在报名送价值1980的实操课。
```

**4. 案例佐证**：
```
上个月有个学员，跟您差不多情况，
之前是个普通文员，学完三个月就开始接客户调理了，
现在每个月额外收入五六千。
我把他学习的反馈发给您看看。
```

**5. 场景描绘**：
```
您想象一下——
三个月后，您已经能独立给人做正骨调理，
家人朋友有身体不舒服，您第一个上手，
那种专业和自信的感觉，那种被需要的成就感...
```

**关键技巧**：
- 价值要在价格之前
- 用故事代替道理
- 用客户的语言说话
- 把学课转化成学“一门终身手艺”

### 阶段4：异议处理（5-8分钟）

**目标**：化解客户顾虑，消除购买障碍

#### 异议处理四步法

**步骤1：表示理解（认同情绪）**
```
我理解您的顾虑...
您有这个担心很正常...
很多人都有这个疑问...
```

**步骤2：挖掘本质（找真实原因）**
```
你觉得贵，是跟什么比贵了？
您主要担心的到底是什么？
```

**步骤3：针对性化解（解决问题）**
```
如果我能证明这个投资值得，您怎么想？
我给您算笔账...
```

**步骤4：确认化解（推动前进）**
```
这样的话，您的顾虑是不是少了很多？
既然这个问题不存在了，咱们接下来怎么推进？
```

#### 常见电话异议速查

**“太贵了”**：
- 本质：价值感不足或预算有限
- 电话话术：先认同，再用投入产出比说话
```
我理解，毕竟是一笔不小的投入。
但我问您一个问题——6980块钱，学会一门能吃一辈子的手艺，您觉得贵吗？
咱算笔账：学6个月，每天不到40块钱，比一顿外卖还便宜。
而且学完之后，接3个调理客户就回本了，以后都是纯赚。
您说是不是这个理？
```

**“我考虑考虑”**：
- 本质：有顾虑但没说出口
- 电话话术：不放弃，也不逼太紧
```
考虑是应该的！我想冒昧问一下——
您主要考虑的是哪方面？是担心学不会，还是担心学了没用？
咱们今天聊这么久了，您心里其实有感觉了对吧。
有什么顾虑您直接跟我说，我帮您分析分析。
```

**“我要跟家人商量”**：
- 本质：需要更多信心或家人支持
- 电话话术：支持商量，提供“商量弹药”
```
完全应该！重大决定肯定要家人支持的。
不过我想多问一句——您家人主要是担心什么？
这样吧，我把课程资料发您一份，
您给家人看看，有疑问随时问我。
要是方便的话，也可以让家人直接跟我聊，我来解答。
```

**“你们比别家贵”**：
- 本质：在比较中
- 电话话术：重新定义比较维度
```
是的，我们确实不是最便宜的。
但选课程不是选白菜，看的是性价比。
有的机构老师自己都没临床过，教的东西能落地吗？
我们的老师都是一线临床出身，教的每一个手法都是验证过的。
您见过太多学员贪便宜报错了，学一半又回来找我们重新学吧？
您的时间也是成本，一步到位比走弯路划算得多。
```

**“我没基础怕学不会”**：
- 本质：对学习能力不自信
- 电话话术：转化劣势为优势
```
零基础完全不是问题！告诉您一个事实——我们80%的学员都是零基础。
中医最怕的是半吊子，懂一点但不系统，这种反而难教。
您零基础是好事，一张白纸，我们教什么您学什么，不走弯路。
我们的课程就是从零开始的，阴阳五行、脏腑经络，一步步来。
跟着老师走，作业按时交，没有学不会的。
```

**“我没时间”**：
- 本质：优先级不够
- 电话话术：重塑时间价值认知
```
我特别理解，您现在工作忙、家里事多。
但我想跟您说句实在话——时间不是有没有的问题，是值不值得的问题。
咱们课程是录播加直播，你上下班路上、晚上睡前都能看。
每天抽1小时，坚持3个月，学会一门能吃一辈子的手艺。
您觉得这时间投入值不值？
您现在没时间，一年后可能还是没时间，
但别人已经学会上手了，您还在原地。
```

**“我想先自学看看”**：
- 本质：想省钱或对付费价值存疑
- 电话话术：用时间成本说服
```
您想先自己看看，这特别理解，网上免费资料确实多。
但说句实话——免费的东西最大问题是零散，东看一点西看一点，学不出系统。
而且中医这行，很多老方法是过时的，费劲学了临床用不上。
我们的课程是成体系的，从基础到临床一路带您走，内容都是更新的。
您自己摸索半年，不如系统学两个月，早学会早受益。
说实话，我见过太多学员自己折腾了一两年，最后回来报班的——何必走弯路呢？
```

### 阶段5：促成成交（8-10分钟）

**目标**：推动客户做出决定

#### 促成成交技巧

**1. 限定优惠法**：
```
王老师，正好这周我们有活动——
今天报名的话，除了课程本身，还送价值1980的实操强化课，
而且名额只剩3个了。
您觉得这个方案怎么样？要不要今天先锁定一下？
```

**2. 算账推动法**：
```
我刚才帮您算过了——
学费6980，学完之后，接3个客户就回本了。
也就是说，3个月之内，这笔投资就收回来了。
而且您考虑得越久，损失的时间越多。
早一天学，就早一天赚钱。您说对吧？
```

**3. 承诺推动法**：
```
这样，王老师，您今天先报个名，
我们支持7天无理由退费。
您先学7天，如果觉得不合适，随时退，一分钱不损失。
但如果您觉得好，就继续学。
这样既降低了您的风险，又能尽快开始，您觉得怎么样？
```

**4. 未来邮件法**：
```
王老师，我想请您闭上眼睛想象一下——
三个月后，您已经学会了正骨技术，
家人朋友身体不舒服，第一个想到的就是您。
那时候您还觉得6980贵吗？
如果现在不行动，三个月后您还在原地。
您想选哪条路？
```

**5. 二选一促成法**：
```
王老师，您想报线上班还是线下班？
线上班随时随地学，线下班有老师手把手教。
您觉得哪个更适合您？
```

**关键技巧**：
- 促成的时机：客户不再提出新的异议时
- 促成的语气：自信、自然、不急
- 促成的底线：不夸大、不欺骗、不逼迫
- 被拒绝后：礼貌收尾，保留后续联系机会

## 三、电话销售关键原则

### 1. 先人后事
先建立关系和信任，再谈课程和价格

### 2. 多听少说
让客户说70%，你说30%。了解才能说服

### 3. 价值先于价格
客户先认同课程价值，价格才不是问题

### 4. 情绪共鸣
客户说“太贵了”，不是反驳而是理解，然后帮客户算账

### 5. 随需应变
根据通话中客户的反应灵活调整，不死背话术

### 6. 礼貌结尾
即使不成交，也要留下好印象，为后续跟进铺路

## 四、不同客户类型的电话策略

| 类型 | 关键词 | 电话重点 |
|------|--------|----------|
| 转行型 | 学手艺、赚钱、创业 | 强调就业前景、收入潜力、创业支持 |
| 养生型 | 调身体、家人健康 | 强调家庭价值、安全实用 |
| 兴趣型 | 学知识、系统性 | 强调体系完整、不走弯路 |
| 进阶型 | 想提升、临床实战 | 强调师资水平、临床资源 |
| 犹豫型 | 怕学不会、决策慢 | 展示零基础案例、低门槛承诺 |

```

- 异议预案：[可能的异议及对策]

## 完整话术脚本
```
